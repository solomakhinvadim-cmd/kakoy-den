# Какой день

Простое приложение для Android и iOS: в выбранное время присылает уведомление «Сегодня среда».

- Любое количество напоминаний в день (до 6), например утром, в обед и вечером.
- Каждое можно включить или выключить переключателем. Нажатие на время меняет его, × или долгое нажатие удаляет.
- Звук можно включить или выключить.
- 4 персонажа: Котик, Листок, Солнышко (вечером становится луной), Квак (у каждого дня свой цвет).
- Кнопка «Проверить уведомление» присылает пробное уведомление через 3 секунды.

Сделано на Expo (React Native) — один код для обеих платформ.

## Запуск на телефоне за 5 минут

1. Установите [Node.js](https://nodejs.org) (версия 20 или новее).
2. В папке проекта выполните:
   ```bash
   npm install
   npx expo install --fix     # подтянет точные версии библиотек под ваш Expo
   npx expo start
   ```
3. Установите на телефон приложение **Expo Go** (App Store / Google Play) и отсканируйте QR-код из терминала.
4. Разрешите уведомления, нажмите «Проверить уведомление».

> В Expo Go локальные уведомления работают. Для настоящей установки (со своей иконкой) соберите приложение — см. ниже.

## Готовые файлы для установки (бесплатно, через GitHub)

1. Создайте пустой репозиторий на github.com и загрузите в него все файлы этой папки (кнопка «Add file → Upload files»; папку `.github` тоже).
2. GitHub сам начнёт сборку (вкладка **Actions**, ~15–25 минут).
3. Готовые файлы появятся во вкладке **Releases**:
   - **kakoy-den.apk** — откройте эту страницу на Android-телефоне, скачайте файл и нажмите на него. Разрешите «установку из этого источника», если телефон спросит.
   - **kakoy-den.ipa** — для iPhone. Apple не даёт ставить приложения просто файлом, поэтому нужен компьютер: установите [Sideloadly](https://sideloadly.io), подключите iPhone кабелем, перетащите `.ipa` и войдите своим Apple ID (бесплатный подходит). На iPhone включите «Настройки → Конфиденциальность → Режим разработчика» и доверьте профиль в «Основные → VPN и управление устройством». С бесплатным Apple ID приложение нужно переустанавливать раз в 7 дней.

## Сборка через Expo (EAS)

```bash
npm install -g eas-cli
eas login
eas build:configure
eas build -p android --profile preview   # .apk — можно сразу поставить на Android
eas build -p ios                         # нужен аккаунт Apple Developer
```

Перед публикацией замените `com.example.kakoyden` в `app.json` на свой идентификатор.

## Как это устроено

- `src/notifications.ts` — для каждого включённого времени ставится 7 еженедельных уведомлений (по одному на каждый день недели), поэтому в тексте всегда правильный день. После любого изменения всё перепланируется.
- На Android два канала уведомлений: со звуком и тихий.
- Настройки хранятся на телефоне (`AsyncStorage`), интернет не нужен.
- `src/themes.ts` — цвета и тексты персонажей, `src/components/Characters.tsx` — сами персонажи (SVG, нарисованы вручную).
- `scripts/make-icons.js` — генерирует иконки в `assets/`.
